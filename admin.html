Private dashboard. Sign in with your GitHub access token, so only you can change the website.

How do I get a token?
  1. On GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens.
  2. Choose Generate new token and set the expiry you want.
  3. Under Repository access pick Only select repositories, then choose your website repository.
  4. Under Permissions set Contents to Read and write.
  5. Generate the token and paste it here. Don't share it with anyone.
